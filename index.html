会员系统（huiyuan2026）

会员制积分商城 + 任务激励 + 推广返现 · 微信小程序 + Vue 管理后台 + Go 后端

作品展示页 · 界面截图预览

项目概述

面向线下门店与线上会员联动的综合运营平台。会员可通过消费、做任务、推广拉新获得积分或现金奖励， 并在门店完成礼品兑换、提现核销等线下履约。系统包含小程序 C 端、Vue 管理后台与 Go REST API。

积分商城 任务中心 推广返现 门店核销 生活电器商城 家政服务 邮件通知 角色权限

技术栈

小程序微信原生小程序
管理后台Vue 3 + Vant
后端Go + MySQL（含 PHP 历史模块）
部署Linux + Nginx + 自动化脚本
